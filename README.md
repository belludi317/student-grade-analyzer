# Student Grade Analyzer

A simple Python program that calculates students' total marks, average marks, and grades.

## Features

- Takes input for multiple students
- Accepts marks for Maths, Python, and OOPS
- Calculates total and average
- Assigns grades based on marks
- Checks individual subject passing marks
- Displays student details in a table

## How to Run

Run the following command:

python student_grade_analyzer.py

## Grade System

- A: 90 and above
- B: 80–89
- C: 70–79
- D: 60–69
- F: Below 60 or failed in any subject
